Read this before quoting a number
---------------------------------
This file previously held a phase-1-only run that reported 100% branch coverage.
That figure was true of what it measured and false of this repository: it was
taken before the market layer existed. The honest headline is the one below —
**73.63% of branches (148/201)** — and the two weakest files are named, not
buried:

  - src/market/CotejoMarket.sol      59.34% branches (54/91)
  - src/market/AdaptiveCurveIrm.sol  63.64% branches (7/11)

The gap is concentrated in argument validation, the shares-denominated paths of
supply/withdraw/borrow/repay, and the administrative surface (revokeIrm,
pendingIrm, external accrueInterest), none of which currently has a test.
`CotejoMarket.sol` is the file that holds user funds, so it is also the file
where this number matters most. It is being worked on; it has not been worked
on yet.

Branch coverage is the number quoted here because it is the one that is hard to
move. Line coverage (95.26%) and function coverage (93.98%) are both higher and
both easier to inflate, so quoting either alone would be selective.
